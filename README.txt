# Abhay Kumar Pandey — Advocate Portfolio Website

A professional, responsive portfolio website for **Abhay Kumar Pandey, Advocate, Patna High Court**.

Designed and developed by **Shantanu Pandey**, this project presents the advocate's professional background, legal practice areas, court and forum information, credentials, and contact details through a clean and accessible interface.

## About the Project

This is a lightweight, static portfolio website built using HTML, CSS, and JavaScript. Its goal is to provide visitors with clear and structured professional information about the advocate.

## Features

- **Professional Homepage** — Advocate introduction and profile.
- **About Section** — Educational and professional background.
- **Practice Areas** — Information about legal practice areas.
- **Courts & Forums** — Professional court and forum details.
- **Professional Details** — Enrollment and other credentials.
- **Contact & Enquiry** — Contact information and enquiry functionality.
- **Responsive Design** — Desktop, tablet, and mobile support.
- **Theme Switching** — Multiple visual themes.
- **Interactive Navigation** — User-friendly navigation.
- **SEO & Accessibility Basics** — Semantic structure and accessible content.

## Getting Started

No framework, backend, or database is required.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/abhay-kumar-pandey-portfolio.git
```

### 2. Open the Project

```bash
cd abhay-kumar-pandey-portfolio
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## Customization

Website content is centrally managed through `data.js`.

- Update advocate information in `data.js`.
- Modify visual design in `style.css`.
- Update page structure in `index.html`.
- Modify interactions in `script.js`.
- Replace images inside the existing `assets/` directory.

## Deployment

The website can be hosted for free using GitHub Pages.

1. Push the project to a GitHub repository.
2. Open repository Settings.
3. Navigate to Pages.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save the settings.
