# Abhay Kumar Pandey — Advocate Portfolio Website

A professional and responsive portfolio website for **Abhay Kumar Pandey, Advocate, Patna High Court**.

Designed and developed by **Shantanu Pandey**, this project presents the advocate's professional background, legal practice areas, courts and forums, professional credentials, and contact information through a clean and accessible interface.

## About the Project

This is a lightweight static portfolio website built using HTML5, CSS3, and JavaScript. It is designed to provide visitors with clear and structured professional information about the advocate.

## Features

- **Professional Homepage** — Advocate introduction and profile.
- **About Section** — Educational and professional background.
- **Practice Areas** — Information about legal practice areas.
- **Courts & Forums** — Professional court and forum information.
- **Professional Details** — Enrollment and professional credentials.
- **Contact & Enquiry** — Contact information and enquiry functionality.
- **Responsive Design** — Desktop, tablet, and mobile support.
- **Theme Switching** — Multiple visual themes.
- **Interactive Navigation** — Smooth and user-friendly navigation.
- **SEO & Accessibility** — Semantic HTML and accessibility considerations.

## Getting Started

No framework, backend, or database is required.

### 1. Clone the Repository

```bash
git clone https://github.com/shantanu-983/abhay-kumar-pandey-portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd abhay-kumar-pandey-portfolio
```

### 3. Run the Website

Open `index.html` in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.

## Customization

The website uses a simple and maintainable file structure:

- `index.html` — Website structure and sections.
- `css/style.css` — Visual design, themes, and responsive styling.
- `js/advocate-data.js` — Centralized advocate information.
- `js/main.js` — Website functionality and interactions.
- `assets/` — Website images and visual assets.

## Deployment

The website can be hosted for free using GitHub Pages.

1. Push the project to your GitHub repository.
2. Open repository **Settings**.
3. Navigate to **Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click **Save**.

GitHub Pages will generate a public website URL after deployment.
